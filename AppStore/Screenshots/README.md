# Screenshot specification

Use JPEG or PNG files without transparency in one of Apple's accepted 16:10
macOS sizes. The 1.0 assets use 1280 × 800.

Prepared 1.0 sequence:

1. `01-reading-window-1280x800.jpg` — rendered Markdown, compact Contents,
   current section, and Live/Read Only status
2. `02-side-by-side-1280x800.jpg` — two Markdown documents in independent,
   arranged windows for comparison

Screenshot files can contain private document content, so image files in this
directory are intentionally ignored by Git. Keep the filenames stable locally
so replacement screenshots are easy to review and upload to App Store Connect.
