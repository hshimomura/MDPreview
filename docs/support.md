# MD Viewer support

## Requirements

- macOS 26 or later
- UTF-8 Markdown files using `.md` or `.markdown`

## Common actions

- Open one or more files with **File > Open Markdown Files…** (`Command-O`).
- Use **Window > Arrange Markdown Windows Side by Side** to compare documents.
- Toggle the chapter outline from the toolbar or View menu.
- Print with `Command-P`; choose **PDF > Save as PDF…** for PDF output.
- Save the file in an external editor to trigger Live Reload.

MD Viewer intentionally does not edit Markdown and does not include a Quick
Look extension.

For bug reports and feature requests, use the
[GitHub issue tracker](https://github.com/hshimomura/MDPreview/issues). Include
your macOS version, the app version, reproduction steps, and a sample Markdown
file with confidential information removed.
